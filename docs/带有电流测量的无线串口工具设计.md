两侧共用同一个PCB，只是不同侧焊接元件不同 全部使用CH570Q

单片机侧的板子设计
- typeC供电 兼容5~12V 通过采样电阻 透传给下一级单片机 
- 通过typeC->LDO 给 CH570Q 供电3.3V 或通过排针直接供电3.3V；注意放置3.3V倒灌LDO
- CH570Q 连接单片机串口RX TX （考虑下发指令可以对调顺序？）RX TX上连着LED可以显示收发状态
- CH570Q 取两个引脚I2C连接INA226
- CH570Q 取1个引脚连接MAX811S在通过一定电路连接单片机NRST 和BOOT引脚实现常规上电或烧录控制；由于 BOOT 先被拉低、约 500~900ms 后 MAX811S 才让 RST# 掉电，短 BOOT 脉冲可能只完成前半段而仍正常启动，固件必须覆盖整个复位释放窗口。Probe 没有 EN 反馈线，当前固件按 900ms 最坏值 + 200ms 稳定观察 + 400ms 裕量保持 BOOT 低电平，共 1500ms。
- CH570Q获取PC侧发来的消息，通过包头1字节识别属于串口通信还是控制命令，转发给单片机串口或执行一定操作
- CH570Q定期获取电流电压采样结果，加上指定包头上报给PC侧
- CH570Q收到单片机的串口消息后转发给PC侧

PC侧的板子设计
- 通过USB 5V供电
- 两个LED，一个展示配对（常亮）通信（闪烁）状态，另一个展示电流大小（PWM调光）和电流报文收发状态（定期闪烁）
- 接收来自CH570Q的数据报文，按照包头区分类型
- 在PC上模拟两个COM设备，一个专用于跟单片机进行串口通信，另一个专用于接收电流采集数据和部分控制命令
