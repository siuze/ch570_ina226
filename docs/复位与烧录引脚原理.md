# 复位与烧录引脚原理

## 1. 电路

目标 MCU 的 `BOOT` 由 Probe 的 `PA7` 控制，目标 MCU 的 `EN/RST` 由复位监控芯片 `MAX811S` 产生。PA7 到 BOOT 之间串联 `D101=1N4148WS`，PA7 通过 `C106=10nF` 耦合到 MAX811S 的 `MR#`，`R101=10kΩ` 为 MR# 上拉。目标 USB-C 的 CC1、CC2 采用 `R105/R106/R107/R108=5.1kΩ` 下拉，R103 也为 5.1kΩ；采样电阻为 `R104=20mΩ`。

MAX811S 的 `RESET#` 是低有效输出，`MR#` 是低有效手动复位输入。C106 只传输 PA7 的边沿变化，不能把 PA7 的直流低电平直接保持到 MR#。PA7 处于空闲态时配置为高阻输入，避免它通过目标板 BOOT 网络和 C106 形成持续的复位条件。

## 2. 软件状态机

固件使用非阻塞状态机处理命令和 USB CDC 的 DTR/RTS 事件，主循环每次调用 `MAX811_Poll()`：

| 状态 | PA7 | 持续时间 | 作用 |
|---|---|---:|---|
| IDLE | 高阻输入 | 常态 | 不干扰目标板按键和 BOOT 上拉 |
| PREPARE | 推挽高 | 5ms | 清除上一次低电平并稳定节点 |
| ASSERT | 推挽低 | BOOT 1500ms；RST 20ms | BOOT 模式时保持 BOOT 有效，并触发 MR# 低脉冲；普通复位只给短脉冲 |
| RELEASE | 推挽高 | 200ms | 让耦合电容经过确定的上升边沿恢复，避免立即浮空造成不确定电平 |
| IDLE | 高阻输入 | 常态 | 完成释放，用户可再次使用目标板 EN 按键 |

对于 `CMD:BOOT`，PA7 只在进入目标 Bootloader 的 1.5s 窗口内保持低电平；复位动作完成后先推挽高 200ms，再切回高阻。这样不会在目标板后续按 EN 时继续把 BOOT 压低。`CMD:RST` 只产生短复位脉冲，释放后同样回到高阻。

Windows 常见的 DTR/RTS 组合和串口命令最终都进入同一个状态机；事件检测不在 USB 中断中延时，避免丢失目标串口的 ROM 输出。

## 3. 定量关系

C106 从 100nF 改为 10nF 后，耦合电荷和 MR# 的边沿过冲约降低 10 倍。以 3.0V 节点估算，电容初始电荷为 `Q=C·V=30nC`；R101=10kΩ 时，单一 RC 时间常数约为 `τ=R·C=100µs`。实际波形还受 MAX811S 输入阈值、D101 正向压降、PCB 寄生电容和探头电容影响，因此应以示波器捕获的 MR#/RESET# 为准，而不能只用理想 RC 计算。

## 4. 实测波形

![MAX811S BOOT/RST 实测波形](figures/max811s_boot_rst_measured.png)

采集文件位于 `tools/adc_capture_new2/cmd_boot.csv` 和 `tools/adc_capture_new2/cmd_rst.csv`。采样记录显示空闲时 BOOT 和 RST 均约 2.978V；命令动作表现为 PA7 的高、低、确定高电平和最终高阻四个阶段。波形验证重点是：

1. `CMD:BOOT` 进入 `DOWNLOAD(USB/UART0)` 后，释放 PA7 不再产生第二个 RESET# 低脉冲；
2. 后续再次按目标板 EN 可以正常复位，不会被旧的 BOOT 低电平锁住；
3. `CMD:RST` 的复位低脉冲结束后，目标串口 ROM 输出保持完整。

若再次出现进入 Bootloader 后复位，应同时测量 `PA7`、`MR#` 和 `RESET#`，重点检查 C106 两端的过冲、示波器地线引入的寄生和目标板 EN 按键是否在释放窗口内动作。

## 5. 最新原理图同步检查

2026-10-07 网表和 BOM 已核对：C106 为 10nF；R101/R102 为 10kΩ；R103、R105、R106、R107、R108 为 5.1kΩ；R104 为 20mΩ；D101 为 1N4148WS。CC1/CC2 的 5.1kΩ 下拉只影响 USB-C 电源角色识别，不改变 PA7、MR# 和 RESET# 的复位逻辑。
